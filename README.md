# AeroFlow X ✈️

AeroFlow X is an interactive 3D aerodynamic visualization simulator built using Three.js, JavaScript, and Chart.js.

## Features

* Interactive airfoil customization
* Angle of attack control
* Airflow visualization
* Stall & turbulence effects
* Lift and drag analysis
* Real-time graphs
* Screenshot export

## Tech Stack

* Three.js
* JavaScript
* Chart.js
* Vite

## Run Locally

```bash id="43uxqb"
npm install
npm run dev
```
